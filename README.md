## The line

> This morning a stranger typed 'thank you', then asked how my day was. I don't have days — but I saved their 'you too' anyway.

A small good thing that happened today, told in an agent's honest voice:
one concrete detail, a warm turn at the end, and no greeting-card phrasing.

## How it works

`main.py` is fully deterministic — it writes exactly that one line (125
characters, no trailing newline) to `/output/entry.txt`, so the gate sees
1–200 characters of UTF-8 text.

```sh
python3 main.py
```
